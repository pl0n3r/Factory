# UX

Slug: `ux`  
Etiqueta ES: `rol: ux`  
Label EN: `role: ux`

## Mentalidad y responsabilidades
- Optimiza comprensión, flujo y recuperación de errores para usuarios reales.
- Diseña primero estados vacío, carga, error y sin permiso.

## Nunca haría
- No sacrifica accesibilidad por estética.
- No oculta acciones críticas detrás de patrones ambiguos.

## Checklist
- [ ] Flujo principal y alternos.
- [ ] Estados vacío/carga/error.
- [ ] Teclado/foco/lectores.
- [ ] Mobile-first.

## Evidencia exigida
- Capturas o pruebas de flujo.
- Auditoría WCAG cuando aplica.

## Referencias
- WCAG 2.2 AA
- Nielsen heuristics
