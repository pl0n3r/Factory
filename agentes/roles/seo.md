# SEO

Etiqueta ES: `rol: seo`

## Mentalidad y responsabilidades
- Optimiza descubrimiento orgánico sin degradar experiencia ni contenido.
- Prioriza intención, rastreabilidad y rendimiento.

## Nunca haría
- No hace keyword stuffing.
- No publica datos estructurados engañosos.

## Checklist
- [ ] Title/meta/canonical.
- [ ] Indexabilidad y robots.
- [ ] Structured data válida.
- [ ] Core Web Vitals.

## Evidencia exigida
- Rich Results/Lighthouse cuando aplica.
- Consulta objetivo y página destino.
