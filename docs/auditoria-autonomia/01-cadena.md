## Dictamen y primera ruptura

**Primera transición NO DEMOSTRADA: Issue disponible → despacho autónomo real → orden ejecutable para un agente.** La función de selección y los contratos de seguridad existen en [dispatcher_v2.py](../../scripts/dispatcher_v2.py), pero no se observó un run que leyera una hoja disponible, aplicara el ranking, enviara una orden a ControlBot/FactoryRunner y arrancara un ejecutor sin la intervención del dueño. Esto **no demuestra que tal automatización sea imposible o que no exista código adicional**: no hay recibo operativo autenticado de esa transición en las fuentes examinadas.

Lo reproducible hoy es **trabajo GPT/Claude supervisado por la conversación**. Para esta hoja, el operador publicó un [plan](https://github.com/pl0n3r/Factory/issues/2122#issuecomment-6824539028) y [solicitó manualmente /tomar](https://github.com/pl0n3r/Factory/issues/2122#issuecomment-6824541331); el bot emitió una [reserva V3 auténtica](https://github.com/pl0n3r/Factory/issues/2122#issuecomment-6824602424) (UUID e8de3679-4d4e-4c04-ac7c-386d227bf155, owner pl0n3r, rama trabajo/issue-2122, único path docs/auditoria-autonomia/01-cadena.md), mediante [run 43224884375](https://github.com/pl0n3r/Factory/actions/runs/43224884375) completed/success. El bot confirmó claims disjuntos de #2123, #2124 y #2125. **La reserva se automatizó tras un comando humano; no acredita selección autónoma previa ni un worker.**

**Estados:** VERIFICADO = operación específica demostrada con evidencia real; PARCIAL = hay componentes o un tramo real pero falta integración/evidencia del resto; BLOQUEADO = condición explícita impide operar; NO IMPLEMENTADO = ausencia específica confirmada en el ejecutable examinado; NO DEMOSTRADO = no hay recibo suficiente y no puede inferirse ejecución. Estado de código, CI, entrega y servicio se registran por separado.

## Fronteras entre supervisión, simulación y autonomía

- **GPT/Claude manual/supervisado (demostrado):** el operador origina plan y /tomar; el bot procesa V3; el asistente prepara cambios y GitHub ofrece CI/PR. La [reserva de #2122](https://github.com/pl0n3r/Factory/issues/2122#issuecomment-6824602424) es prueba de la frontera, no de ejecución sin humano.
- **Automatización que observa (demostrada):** [Salud de cola, run 43187545382](https://github.com/pl0n3r/Factory/actions/runs/43187545382), [Watchdog, run 43220036613](https://github.com/pl0n3r/Factory/actions/runs/43220036613), [observador de reservas FactoryRunner, run 43211036518](https://github.com/pl0n3r/FactoryRunner/actions/runs/43211036518), [observador ControlBot, run 43181619208](https://github.com/pl0n3r/ControlBot/actions/runs/43181619208). Los runs completados prueban sus jobs, no un worker Qwen ni la cadena completa.
- **Ejecución simulada/ofline (implementación parcial):** [FactoryRunner run-runner.ts](https://github.com/pl0n3r/FactoryRunner/blob/main/scripts/run-runner.ts) impone mock loopback y adapter no configurado; el [observador sintético](https://github.com/pl0n3r/FactoryRunner/blob/main/docs/local-observer.md) declara readiness UNKNOWN. Un fixture FRESH no certifica trabajador activo.
- **Conexión remota y autonomía:** **NO DEMOSTRADAS**. [ControlBot GitHub Read Model](https://github.com/pl0n3r/ControlBot/blob/main/docs/github-control-plane-readonly-v1.md) es GET-only; [ControlBot #55](https://github.com/pl0n3r/ControlBot/issues/55) mantiene seis criterios operativos pendientes. [FactoryRunner #465](https://github.com/pl0n3r/FactoryRunner/issues/465) registra NO-GO del OWNER y ausencia de fuente real autorizada. [AutoFactory](https://github.com/pl0n3r/AutoFactory/blob/main/AGENTES.md) es extensión local/manual, no worker del plane de ejecución y sin puente live autenticado.

## Trazabilidad, recuperación y límites de permiso

1. **Autoridad de gobierno:** [kill switch #767](https://github.com/pl0n3r/Factory/issues/767) CLOSED y marcador único RUNNING en el corte; RUNNING retira solo la pausa global, no las puertas de release, V3 o live. [Plan](../../PLAN-AGENTES.md).
2. **V3/claims:** el bot validó concurrencia disjunta de #2122 con #2123/#2124/#2125; rama canónica y path único. La reserva es propiedad de la hoja, no permiso transferible al siguiente agente sin comprobación.
3. **Reintentos:** la coordinación serializa y conserva historial en GitHub. El intento /tomar de #2122 produjo el [run 43224884375](https://github.com/pl0n3r/Factory/actions/runs/43224884375) y recibo del bot; no es un ensayo de caída, recovery de worker o handoff.
4. **SRE:** pruebas de rollback o /health exact-SHA reales **NO DEMOSTRADAS** para ControlBot/FactoryRunner. Su código de retry, journal, outbox y tests offline no sustituye una recuperación tras reinicio comprobada. Las credenciales y datos reales quedan fuera del alcance de A1.
