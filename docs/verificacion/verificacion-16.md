## Semántica y límites

No se promueve ninguna fila a `CUBIERTO` por el solo hecho de aportar un testigo sintético: la promoción corresponde a la consolidación autorizada y requiere código causal, prueba exacta y PR fusionado. Este informe refleja pruebas verificables locales **sin demostrar operación real** ni autoría del OWNER, autorización para gastos/production, SLO observados o despliegues. Un testigo enlaza un método preexistente que el nuevo test ejecuta efectivamente; una observación offline no demuestra el 100 % de un predicado operativo.

- `SINTETICO`: existe un testigo ejecutable directo para el contrato local; no implica promoción automática.
- `LIMITE_GOBERNANZA`: la prueba del parser o del runbook no certifica decisión humana, autoría de edición o acatamiento de agentes remotos.
- `LIMITE_OPERATIVO`: falta observación externa válida de CI/HEALTH/cadencia/permisos/acciones reales; no se inventa.
- `LIMITE_INTEGRACION`: proyección local y límites fail-closed, consumidor o entrega real aún no acreditados.
- `BRECHA_EPIC_304`: existe evidencia parcial del subsistema Performance, pero #304 permanece abierto y no se acredita la totalidad de sus AC.
